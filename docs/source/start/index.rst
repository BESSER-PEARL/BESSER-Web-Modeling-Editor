Start here
==========

For your first visit, use the hosted editor and follow
:doc:`../tutorials/first-project`. You will create two classes, connect them,
validate the diagram, and download a source file.

Prefer describing your system? Choose **Describe it** on the welcome screen
or **Agentic** when creating a new project. The
:doc:`assistant guide <../user-guide/ai-assistant>` explains the review and
generation flow. Check :doc:`../user-guide/ai-keys` for provider availability.

The :doc:`setup guide <../overview/getting-started>` is for running your own
editor. It is not required to use the hosted version.
