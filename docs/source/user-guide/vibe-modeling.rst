Vibe Modeling (moved)
=====================

This page has moved to :doc:`ai-assistant`.

"Vibe modeling" was an internal name that never appeared in the product. The
two things it covered are now documented separately, because they are two
different features:

* :doc:`ai-assistant` — the **Modeling Assistant**, the chat that builds and
  edits diagrams for you.
* :doc:`spec-driven-agent` — the **Spec-Driven Agent**, which turns a finished
  model into a running application.
